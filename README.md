# TONVISIT — сайт-визитка крипто-компании с оплатой в TON

Одностраничный сайт для крипто-компании: услуги, кейсы, команда, отзывы, FAQ и
**приём оплаты в крипте прямо на странице** через экосистему TON.

Полностью статический: чистый HTML + CSS + JavaScript, **без фреймворков, без сборки и
без бэкенда**. Деплоится на Netlify перетаскиванием папки.

---

## ⚡️ Быстрый старт

Вам нужно сделать ровно одно — указать свой кошелёк и тексты в одном файле:

```
src/js/config.js
```

Ключевая строка:

```js
payment: {
  wallet: 'ЗДЕСЬ_ВАШ_КОШЕЛЁК_TON',  // напр. UQAdrWJyteNbSPn9NHWjOKssHWeL9ZbAFFclIf8EUtsMcXJM
}
```

Как узнать свой адрес: откройте Tonkeeper → «Copy address». Поддерживаются форматы
`EQ…` (bounceable), `UQ…` (non-bounceable) и `0:…` (raw).

> ✅ **Кошелёк уже прописан:** `UQAdrWJyteNbSPn9NHWjOKssHWeL9ZbAFFclIf8EUtsMcXJM`
> (raw: `0:1dad6272b5e35b48f9fd3475a338ab2c1d678bf596c014572521ff0452db0c71`).
>
> ⚠️ Перед приёмом живых платежей сделайте тестовый перевод на 0.01 TON и убедитесь,
> что «Проверить оплату» его находит. И не отправляйте всю сумму на кошелёк, который
> нельзя выгрузить в-seed до продакшена.

Затем локальный запуск:

```bash
npm install     # только для тестов (jsdom); сам сайт зависимостей не имеет
npm run dev     # http://localhost:5173
```

## 🚀 Деплой на Netlify

Сборка не нужна — Netlify просто публикует файлы как есть.

### Способ 1. Перетаскивание (самый быстрый)

1. Откройте [app.netlify.com/drop](https://app.netlify.com/drop)
2. Перетащите папку проекта (или её zip-архив)
3. Готово — сайт доступен на `*.netlify.app`

### Способ 2. Git-репозиторий (для CI/CD)

```bash
git init && git add . && git commit -m "TONVISIT: сайт-визитка"
git remote add origin git@github.com:ВАШ_АККАУНТ/tonvisit.git
git push -u origin main
```

Затем в Netlify: **Add new site → Import an existing project** и укажите репозиторий.
Настройки берутся из `netlify.toml` автоматически:
- publish directory: `.`
- build command: ничего (статика)
- 404: `404.html` подхватывается сам

### Способ 3. Netlify CLI

```bash
npm i -g netlify-cli
netlify login
netlify deploy --prod --dir .
```

## 💎 Как работает оплата в TON

Ниже — полная схема. Бэкенда нет, всё делается на стороне браузера.

1. **Клик «Оплатить»** → создаётся заказ с ID вида `TV-A1B2C3D` и сохраняется в
   `localStorage` браузера.
2. **Комментарий** к переводу формируется автоматически: `TV-A1B2C3D-audit` — это
   ключ для сверки платежа.
3. **Ссылка** `ton://transfer?address=…&amount=…&text=…&exp=…` открывает любой кошелёк
   сети TON с уже подставленной суммой и комментарием. Работает в Tonkeeper,
   Telegram Wallet, Tonhub, MyTonWallet. Внутри — QR-код и возможность скопировать
   адрес вручную. **Порядок параметров важен:** `address` обязан идти первым, иначе
   кошелёк показывает «Неверная ссылка». `amount` — целое число нанотонов,
   `exp` — срок действия ссылки (24 часа), чтобы старый QR не отправил
   деньги по неактуальной цене.
4. **«Проверить оплату»** → сайт обращается к публичному API
   [`tonapi.io`](https://tonapi.io) и ищет входящую транзакцию, где:
   - получатель = ваш кошелёк (в raw-формате `0:…`),
   - сумма ≥ суммы заказа,
   - комментарий совпадает с ID заказа.
5. **Подтверждение** занимает 10–30 секунд. Проверка повторяется автоматически каждые
   6 секунд, пока платёж не найдётся.

### Что важно понимать

| Момент | Реальность |
|---|---|
| Где живут заказы | В `localStorage` браузера. Это не база данных — это генератор ID и комментария для сверки. |
| Кто подтверждает заказ | Сначала автопроверка по сети. Финальную отметку «оплачено» ставит человек после сверки с кошельком. |
| Нужна ли база для учёта | Да, если хотите историю всех заказов. Варианты: Telegram-бот, Airtable/Google Sheets, Supabase. Сейчас этого нет намеренно — сайт работает без бэкенда. |
| TON Connect | Не используется: он требует бэкенда для проверки подписи. Deep-link работает во всех кошельках и не требует ничего. |

> 💡 **Практический совет.** Комментарий в сети TON может обрезаться (зависит от
> кошелька). Код это учитывает: если комментарий пришёл пустым, сверка идёт только по
> сумме и времени. Не отправляйте одну и ту же сумму дважды подряд — при сомнениях
> попросите клиента прислать ссылку на транзакцию.

## 📬 Заявки уходят в Telegram

Форма в секции «Заявка» — единственный способ связи на сайте. Email, телефон и
кошелёк намеренно не публикуются.

Как работает отправка (без сервера и без Netlify Forms):

1. Пользователь заполняет **имя**, **Telegram** и **задачу**.
2. Сайт собирает из них текст заявки и копирует его в буфер обмена.
3. Открывается чат `https://t.me/<ваш ник>` — остаётся вставить и отправить.
4. Если вставить неудобно, под полем формы появляется прямая ссылка на Telegram.

Ник нормализуется автоматически: `qeinq`, `@qeinq`, `t.me/qeinq` и
`https://t.me/qeinq` превратятся в `@qeinq`.

Антиспам: скрытое honeypot-поле `bot-field` + проверка обязательных полей с
подсветкой. Если JavaScript выключен — показывается запасная ссылка на Telegram.

> 💡 **Хотите, чтобы заявки приходили без действия пользователя** (письмом, в
> CRM или в бота)? Тогда понадобится либо Netlify Function с Telegram Bot API,
> либо возврат к Netlify Forms. Текущий вариант выбран сознательно: он работает
> сразу, без токенов, ключей и настроек.

Цена в GRAM и в USD задаётся независимо: `priceTon` — то, что платит клиент,
`priceUsd` — справочная цифра для сравнения («было / стало»). Курс GRAM→USD
подтягивается живой с `tonapi.io` и обновляет строку «≈ $» после загрузки страницы.

### Валюта: сеть TON, монета GRAM

Это не одно и то же, и путаница тут стоит дорого. **Сеть называется TON, а её
нативная монета — GRAM.** В кошельках она отображается как `GRAM (ex-Toncoin)`.
Цена и суммы в крипте на сайте — в GRAM; курс берётся у сети, а не зашит в код.

Если tonapi.io снова поменяет формат ответа, страница не сломается: она
останется на запасном курсе `FALLBACK_USD_RATE` (`src/js/main.js`), который
задан примерно актуальным значением. Проверить, что живые данные доходят,
можно так:

```bash
curl -s 'https://tonapi.io/v2/rates?tokens=gram&currencies=usd'
# {"rates":{"GRAM":{"prices":{"USD":1.5668},...}}}
```

Старый вызов `?base=ton&symbols=usd` **больше не работает** — API отвечает
ошибкой `query parameter "tokens" not set`. Из-за этого сайт молча
показывал завышенные цены (фолбэк стоял 3.0 вместо реальных ~1.57).

### Про скролл при перезагрузке

Браузер по умолчанию запоминает, где посетитель остановился, и возвращает его туда
же по F5. На лендинге это читается как баг, поэтому поведение отключено в двух местах:

- **`src/js/scroll-top.js`** (подключён синхронно в `<head>`) — ставит
  `history.scrollRestoration = 'manual'` и уводит страницу наверх. Скрипт
  запускается раньше всего остального JS, иначе браузер успевает восстановить
  позицию. Отдельный файл, а не инлайн-код: в `netlify.toml` выставлен
  CSP со `script-src 'self'` **без** `'unsafe-inline'`, и инлайн-скрипт
  заблокировался бы в проде.
- **`initAnchors()` в `main.js`** — клики по `href="#…"` обрабатываются в JS,
  а сам якорь убирается из адреса через `replaceState`. Иначе после перехода
  по меню в адресе оставалось бы `#contact`, и F5 снова кидал бы вниз.

**Не ставьте `defer`/`async` на `scroll-top.js`** — с ними он выполнится после
того, как браузер уже восстановит позицию, и перестанет работать.

Прямые ссылки вида `site.com#faq` продолжают работать: если в адресе есть якорь,
скрипт не трогает скролл, и браузер сам прокрутит к нужной секции.

## 🔒 Безопасность

Уже настроено в `netlify.toml`:

- `Content-Security-Policy` — скрипты только свои, сеть только `tonapi.io`
- `X-Frame-Options: DENY` — сайт нельзя встроить в чужой iframe
- `X-Content-Type-Options: nosniff`
- `Referrer-Policy: strict-origin-when-cross-origin`

В коде: весь текст из конфига экранируется (`esc()`), ссылки проходят белый список
протоколов (`safeUrl()` — `javascript:` блокируется). Honeypot защищает форму от ботов.
